# Mechanical-Room-Automation
A Dynamo script that automatically extracts mechanical equipment data from Revit to Excel

# Mechanical Room Equipment Schedule Automation

## 📌 Problem
Manually creating equipment schedules in Revit is time-consuming and prone to human error. Engineers often spend hours copying data from the model into Excel, and missing data can go unnoticed until late in the project.

## 💡 Solution
I created a Dynamo script that automatically:
1. Selects all Mechanical Equipment in a Revit model.
2. Extracts custom BIM parameters (Equipment ID, Equipment Type, Flow Rate, Head).
3. Exports the data into a formatted Excel schedule.

## 🛠️ Tools Used
- Autodesk Revit 2026
- Dynamo 2026
- Microsoft Excel
